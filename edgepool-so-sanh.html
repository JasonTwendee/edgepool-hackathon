Edgepool: so sánh Design và bản Dev

Design = edgepool-app-offline.html (file export). Dev = edgepool-dev.tailec308e.ts.net. Chụp ở viewport ~800px và 375px, ngày 07/10/2026. File export mở bình thường, đủ style; các lệch bên dưới là do bản dựng lại.

Tóm tắt
  • Dev đã lấy đúng màu và font từ tokens.css nhưng không bám layout và component trong file .dc.html.

9. Chi tiết chung và phần chưa so được P2

  • Icon: design dùng Phosphor regular (nav, meter slots, mũi tên CTA…); dev gần như không có icon.
  • Số và nhãn: design dùng mono cho mọi số và nhãn như LIVE, nhãn KPI/section là uppercase 11px; dev dùng chữ thường ở nhiều chỗ.
  • Thiếu theo bundle JS của dev: chip pipeline signal, “Coming soon / Notify me”, toast, 25%/50% trong Withdraw, Wallet modal, dashboard partner đầy đủ, Time stop, Execution log, “Today”.
  • Dev đã có logic: Withdraw, Claimable / Paid to date / payout wallet, My pools, Pending withdrawals, mask ••.
  • Dữ liệu khác nhau không tính là lỗi: dev dùng data thật (8 pool, NAV 421.44 …), design dùng data mẫu (NAV 412.60 …).
  • Chưa soi: My position / Portfolio / Withdraw khi đang giữ vị thế; Trader dashboard (cần tài khoản partner); pool Paused, pool đầy; tablet 768px; focus ring; Esc đóng modal.
