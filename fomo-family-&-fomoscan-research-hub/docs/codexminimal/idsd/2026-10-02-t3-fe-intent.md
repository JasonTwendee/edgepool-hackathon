# Intent — T3 FE fund (auth + admin panels + DEMO labels)

- Date: 2026-10-02
- Stage: intent-bounded → execution (FE only, không đụng BE contract)
- Parent: fund intent Rev 2 P5-T3, fund spec §§11–13 (demo principle), §3–4 (roles).

## 1. Intent contract

- **Intent**: FE cho phép login ví (nonce→ký ngoài→verify), ADMIN thao tác
  users/audit/vaults/traders/policy/bots/tick ngay trên dashboard, và mọi màn hình
  gắn nhãn DEMO/SIMULATED显式 — audience thấy full product flow, không chạm real fund.
- **Business rules**:
  - Signing UX: BE không giữ key → panel hiện message để user ký ngoài
    (Phantom dapp / CLI / script) rồi paste signature; kèm lối tắt paste-token
    (dev/operator) ghi rõ nhãn.
  - Token trong `localStorage` (`fomo.session`), mọi admin call kèm Bearer;
    401/403 hiện message BE nguyên văn (không giấu).
  - Routes public cũ không đổi; AdminPanel chỉ hiện khi user bật (không chiếm layout).
  - DEMO banner tĩnh + badge `sandbox` ở VaultCard — không logic BE mới.
- **Non-goals**: wallet-adapter tích hợp, FE route-guard theo role, đổi theme,
  mobile layout mới, chart mới.
- **Acceptance**: login thật (nonce→verify→me) trên FE; ADMIN tạo vault/assign/
  pause bot/tick từ UI; USER thấy 403 đúng message; `tsc` + `next build` xanh;
  banner DEMO hiện ở :3001.

## 2. Decisions

- D-T3.1 paste-signature thay vì wallet-adapter: zero dep mới, khớp "manual where
  necessary during development"; adapter là follow-up.
- D-T3.2 session state lift lên `page.tsx` (AuthPanel + AdminPanel dùng chung),
  persist localStorage.
- D-T3.3 AdminPanel là overlay thay TraderProfile khi bật (không đụng layout 4-block).

## 3. Bounded spec (FE)

1. `types/fund.ts`: User/AuthNonce/AuthSession/AuditLog/VaultTrader/VaultWithTraders/
   Bot/AutoFireTickResult + `FundSession`.
2. `lib/api.ts` += `fetchJsonAuth` + auth/admin/vaults/bots/tick client fns;
   `VaultStatusResponse` += environment/treasurySol/policy.
3. `components/DemoBanner.tsx` (mới, tĩnh).
4. `components/AuthPanel.tsx` (mới): nonce→message→verify + paste-token + me + logout.
5. `components/AdminPanel.tsx` (mới): tabs Users/Audit/Vaults/Bots/Engine.
6. `page.tsx`: session state + banner + toggle admin; `VaultCard`: badge sandbox +
   treasury/policy hiển thị.
7. Verify: `tsc` + `next build` + live `:3001` 200 + banner text trong HTML.

## 4. Test contract / agents / risks

FE không có runner → `tsc` + `next build` + smoke thủ công checklist (login/logout,
403 USER, admin CRUD, tick). Primary generic; gate review FE (token handling:
không log token, logout xóa). Rủi ro: token XSS-theft (mitigate: localStorage là
chuẩn SPA demo; production cần httpOnly cookie — ghi follow-up, không làm slice này).
